# MedGuard AI Frontend v1.1 — 7 Requested Upgrades

1. **Transaction Investigation Screen** — full detail view for a review event with linked bill, payment, inventory and camera evidence.
2. **Evidence Timeline + CCTV Review** — simulated evidence player, event marker, timeline and human-review actions.
3. **Camera AI Zone Editor** — cash counter, high-value medicine, entrance and custom-zone configuration UI.
4. **Detailed Connector Wizards** — step-based connection setup for source, access, data mapping and testing.
5. **Advanced Owner Away Mode** — monitoring level, alert routing and priority-rule selection.
6. **Opening / Closing + Failure States** — business-day assistants, diagnostics and failure/fallback previews.
7. **Medical Software Connector Catalog** — retail pharmacy and pharma distributor/agency software choices with connector templates.

> The connector catalog is a frontend setup experience. Actual direct integrations are not yet implemented and will depend on the supported API/database/export mechanisms available for each installed product/version.
